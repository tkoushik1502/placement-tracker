\# Placement Tracker



A full-stack MERN application designed to help students track campus placement opportunities, applications, deadlines, and application status in one centralized platform.



\## 🚀 Features



\### Student Features

\- Student registration and login

\- Secure JWT-based authentication

\- Student profile management

\- Browse available companies

\- View company and job details

\- Apply for placement opportunities

\- Track submitted applications

\- View application status

\- Dashboard with placement information



\### Admin Features

\- Admin authentication

\- Add and manage companies

\- View student applications

\- Manage application information

\- Monitor placement activities

\- Admin dashboard



\### System Features

\- Role-based access control

\- Protected routes

\- RESTful API architecture

\- MongoDB database

\- JWT authentication

\- Password hashing

\- Responsive React interface

\- Centralized API handling

\- Authentication error handling
